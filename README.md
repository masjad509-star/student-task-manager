# Student Task Management System

A small browser-based application that lets students view and add tasks.
It is the continuing project for a DevOps assignment series
(Git -> GitHub -> Maven -> Jenkins -> Terraform -> Deployment -> Monitoring).

## Purpose
Provide a simple, real project for practising version control and DevOps workflows.

## Current Features
- Add a task with title and description (blank input rejected)
- Three sample tasks

## File Structure
- index.html - page structure and form
- style.css - responsive layout and styling
- script.js - add-task, validation and (later) status/priority logic
- README.md - project documentation
- .gitignore - files excluded from version control

## Usage
Open index.html in any modern web browser. Enter a title and description, then click "Add Task".

## Future DevOps Work
Maven project structure, automated tests, Jenkins CI, Terraform provisioning, deployment and monitoring.
